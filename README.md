# Football Player Generator

A small collection of Python scripts for football-themed games, built with a shared pool of player names and ratings.

## Scripts

- **`randomfootballgeneratorgame.py`** — Two players each get a random footballer; whoever's footballer has the higher rating wins.
- **`averagefootballerratinggenerator.py`** — Pick 5 footballers by name and see your squad's average rating.
- **`claudecodefantasyfootball.py`** — Draft a 5-player squad within a budget and play a round against an AI drafter, comparing average squad ratings.

## Running

Each script is standalone and requires only the Python standard library (Python 3):

```bash
python3 randomfootballgeneratorgame.py
python3 averagefootballerratinggenerator.py
python3 claudecodefantasyfootball.py
```
